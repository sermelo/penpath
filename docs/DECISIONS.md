# Decisions

- 2026-11-23 — LUC-30 likeness scoring: keep SSIM via scikit-image (greyscale, 256x256, blur sigma 1.5) as the measure; widen numpy from `>=1.26,<2` to `>=2.4,<3` so Python >=3.14 installs a compatible wheel instead of source-building unsupported numpy 1.26 on CI (sergio approved via confirmation card 64e0f31d); use pixels-per-millimetre (default 96/25.4) as the single scale unit shared by `compute_likeness` and `simulate_plot`.
- 2026-11-23 — LUC-31 CLI preview/evaluate: use that single pixels-per-millimetre unit for both the simulation and the likeness crop (no second "dpi" unit); `evaluate --json` writes only the JSON object to stdout and sends human tables to stderr so scripts can pipe it straight into `jq` (Architect direction in LUC-31).
- 2026-11-23 — LUC-41 SVG parsing: treat `<polygon fill="none">` as a closed polyline whose length includes the closing edge back to the first point; keep skipping polygons with a fill, since those are shapes rather than strokes, so vpype output is fully visible to the simulator.
- 2026-11-23 — LUC-42 vpype placement: scale image geometry into the `fit_image_placement` rectangle with the direct export's `_scale_geometries_to_placement` helper before handing it to vpype in pixels, drop `--center` when a placement is given so vpype cannot move the ink, and write the pen width via vpype's `penwidth` command so previews use the real stroke width; callers without a placement keep the old centred behaviour.
- 2026-11-23 — LUC-43 machine cost: `parse_svg_strokes` gains opt-in `include_pen_up` (default false) that inserts a straight two-point travel stroke between non-contiguous strokes when the gap exceeds 0.01 mm, using the following stroke's colour and width; `compute_machine_cost` counts `num_strokes` for pen-down strokes only; `penpath evaluate` opts in so travel and lifts are real, while `preview` and default library calls are unchanged.
- 2026-11-23 — LUC-44 vpype pen identity: write each pen's colour and Inkscape layer label into its vpype layer with `color --layer <id>` and `name --layer <id>`, sourcing both from the same `Pen` and the shared `_pen_layer_label` helper used by the direct export; vpype normalises CSS colour names to hex, so the two paths agree on colour semantically rather than textually.
- 2026-11-23 — LUC-46 seed propagation: `PFMSettings.to_typed_settings()` now unwraps the nested `settings` payload (as `SketchLinesPFM` uses) before building the typed settings model, so `-s seed=42` reaches the algorithm; flat PFM layouts pass through unchanged and `seed` still defaults to `null`. This makes scores from `penpath evaluate` comparable between runs of the same command.
- 2026-11-23 — LUC-49 convert output path: the optional positional `OUTPUT_PATH` and `-o/--output` are equivalent ways to name the SVG; when both are given, compare the normalised paths and accept only equal paths, otherwise fail with a usage error (exit 2) naming both. The optional vpype dependency is the `vpype` extra, so the install hint is `pip install "penpath[vpype]"`; vpype stays optional and the CLI falls back to direct SVG export without it.
- 2026-11-24 — LUC-51 D5 profile schema: `MachineProfile` and its section models validate the agreed bed/feed/pen/gcode/pen_change shape, forbid unknown keys so typos fail loudly, and check that Z heights are ordered, a ramp has both touch and hover, nozzle ranges increase and each pen-change step has one action; the schema holds no file I/O and no machine values.
- 2026-11-24 — LUC-51 D2 (machine profiles): the profile is the only home for machine values; `core/profiles.py` holds the schema and no numbers, and built-in profiles are YAML data under `presets/profiles/` read with `importlib.resources` (LUC-51 plan revision 2).
- 2026-11-24 — LUC-50 D3 (palette model): `Palette(name, pens)` holds pens in drawing order; `Project.pen` is optional, `Project.pens` is the ordered list, and `Project.palette` returns `pens` or the single `pen`, so old project files keep working and `Pen.name` is the layer label.
- 2026-11-24 — LUC-50 D4 (CLI and YAML surface): `--palette` accepts a built-in name or `name=width,#hex;...`, is exclusive with `--pen`, and YAML accepts `palette:` or `pens:` but never together with `pen:`; palette order is drawing order and a user list is used exactly as given.
- 2026-11-24 — LUC-50 D5 (Stabilo palette): the built-in `stabilo_88` palette has twelve 0.4 mm pens named `stabilo_88_<colour>` in light → dark order, with approximate hex values in one table in `presets/palettes.py`; `penpath info palettes` shows that order.
- 2026-11-23 — LUC-53 erase model: a drawn segment adds `int(erase_min + y_progress * (erase_max - erase_min))` to each pixel it covers, saturating at 255, with `y_progress = 0.5*x^3 + 0.5*x` and `x = luminance/255`; defaults `erase_min=50`, `erase_max=125`, `tone=0.5` match DrawingBotV3, so dark areas keep receiving ink while light areas stop early.
- 2026-11-23 — LUC-53 endpoint rule: a candidate ray ends at the pixel where the running mean luminance of the sampled prefix is lowest (only prefixes longer than `min_length` qualify); reaching the image edge ends the ray at its last in-bounds pixel instead of counting a failure, and every emitted coordinate is clamped inside the image.
- 2026-11-23 — LUC-53 stop condition: drawing stops when `(mean - initial) / ((253.5 - initial) * line_density) >= 1`, not on an invented line count; `line_density` defaults to the reference 0.75 and shading defaults off. With `erase_enabled=False` the image never lightens, so a hard stroke cap (200 for normal images) ends the run and the result is deliberately dense and dark.
- 2026-11-24 — LUC-53 gate: part 1's thresholds are asserted verbatim and neither lowered nor skipped. Measured with part 1's harness unchanged (vpype 1.15, seed 42): SSIM circle 0.5681, gradient 0.5051, sphere 0.8362, face 0.6189, photo 0.2064, all below the floors 0.75/0.80/0.88/0.70/0.75; sphere ink share 0.0002 < 0.0003 and photo tone ratio 1.59 < 2.0 also fail. The reference semantics are ported; reaching the floors needs the default calibration owned by part 3, so the Architect decides in LUC-47.
